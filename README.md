# Learning Godot by Rebuilding Asteroids

The Godot project for my blog series [Learning Godot by Rebuilding Asteroids](https://circleseven.co.uk/series/learning-godot-by-rebuilding-asteroids/), where I learn the Godot game engine from scratch by rebuilding Atari's 1979 arcade game as closely as I can.

To get a part's code, pick its tag from the branch menu on GitHub, or run `git checkout part-03`, for example.

## Running it

1. Install [Godot](https://godotengine.org) 4.7 (the standard version, not .NET).
2. In the Project Manager, click Import and choose this folder's `project.godot`.
3. Press Cmd+B (Ctrl+B on Windows and Linux) to run it.

The controls are the arrow keys: Left and Right to turn, Up to thrust.
